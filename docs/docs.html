Documentation

Everything you need to use pycompile. The same content is available as a man page: man pycompile or pycompile man.

Overview

pycompile is an ahead-of-time compiler that translates a supported subset of Python into C, invokes the platform C compiler, and emits a single standalone native executable. There is no interpreter and no runtime dependency at run time.

It targets small command-line programs and scripts where you want Python's syntax and iteration speed, but a portable native binary as the deliverable.

Usage

pycompile [OPTIONS] <INPUT> [-- PROGRAM_ARGS...]
pycompile man [--install] [--prefix DIR]

<INPUT> is a .py file, or a directory containing main.py or __main__.py. When it is a directory, pycompile looks for main.py first, then __main__.py, and compiles that file as the entry point.

-h, --helpPrint a usage summary and exit.

Language support

Compiles to native code

  • Integer, float, string and boolean literals, and None
  • f-strings with format specs and the !r conversion
  • Lists, tuples, sets and dicts, including literal and comprehension forms
  • if / elif / else, while, for-in (with else), break, continue, pass
  • def with default parameters, recursion, and *args / **kwargs parameters
  • Calls with positional, keyword, * and ** arguments
  • Chained comparisons, in / not in, is / is not, and, or, not
  • Slicing and item assignment, augmented assignment
  • % string formatting (positional and mapping forms, flags, width, precision)
  • lambda expressions, nested functions and closures (including late binding and sorted(..., key=lambda ...))
  • try / except / except ... as name / else / finally, raise, assert, and catchable built-in exception types with their inheritance hierarchy
  • Stable sort / sorted with reverse=True and key=
  • class definitions with methods, __init__, class and instance attributes, single inheritance, isinstance, and the __str__, __repr__, __eq__, __len__, __getitem__, __setitem__ and __contains__ protocols
  • The math and sys modules

Not yet supported

These produce a clear compile-time error rather than silent misbehaviour:
  • super(), multiple inheritance and decorators (@staticmethod, @classmethod)
  • with, generators, async and await
  • return, break or continue inside a try that has a finally clause
  • Modules other than math and sys

Runtime model

The generated C links against a small runtime library that is embedded by the compiler. Values are heap-allocated tagged objects.

A conservative mark-and-sweep garbage collector reclaims unreachable objects by scanning the C stack, the program's globals and a few runtime roots. Reference cycles that stay unreachable are collected as well. Because the scan is conservative, an object can occasionally be kept alive a little longer than strictly necessary.

Runtime errors raise the corresponding built-in exception (for example ZeroDivisionError, IndexError, KeyError, TypeError, ValueError, AssertionError and RuntimeError), which can be caught with try / except. An uncaught exception prints a Python-style traceback to stderr and exits with status 1.

Examples

# Compile a single file
pycompile hello.py

# Choose an output path
pycompile hello.py -o build/hello

# Compile and immediately run
pycompile -r hello.py

# Keep the generated C for inspection
pycompile hello.py --emit-c hello.c --keep-temps

# Compile a project directory
pycompile ./myproject -o myproject

# Pass arguments to the compiled program
pycompile cli.py -o cli -- --verbose file.txt

Limitations

  • The garbage collector is conservative: it may keep an unreachable object alive a little longer than necessary, and it scans the whole C stack on each collection.
  • super(), multiple inheritance and decorators are not supported.
  • A return, break or continue inside a try that has a finally clause is rejected at compile time.
  • Uncaught exceptions print a single-line traceback (no file/line frames).

Reporting issues

pycompile is developed on GitHub. Bugs, crashes, wrong output and missing features all go to the issue tracker.

  1. Search the existing issues first.
  2. Open a new issue at github.com/ramackersjp/pycompile/issues/new.
  3. Include your pycompile --version, your operating system, the command you ran, a minimal Python snippet, and the expected versus actual output.

A GitHub account is required to open an issue; there is no separate bug tracker or mailing list.
