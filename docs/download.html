Change log

Added

  • % string formatting in runtime/pyrt.c (percent_format): %s/%r/%a, integer and float conversions, flags (- 0 + space #), width, precision, %%, and mapping form %(name)s, matching CPython output.
  • lambda expressions, nested functions and closures: cell objects (PY_CELL, py_cell_new/py_cell_get/py_cell_set), free-variable analysis and py_closure, with late binding and closures over enclosing locals and parameters (src/ast.rs, src/parser.rs, src/codegen.rs, runtime/pyrt.c).
  • Exception handling: try / except / except ... as name / else / finally, raise (bare, raise E, raise E(...)) and assert. The runtime uses setjmp/longjmp handlers and a hierarchy of built-in exception types (ZeroDivisionError, IndexError, KeyError, TypeError, ValueError, AssertionError, RuntimeError, ...). Runtime errors now raise catchable exceptions; uncaught exceptions print a traceback and exit 1.
  • Conservative mark-and-sweep garbage collector (runtime/pyrt.c): objects are tracked in an intrusive list and a hash set; collection scans the C stack, the registered global roots and a few runtime roots, marks reachable objects and frees the rest, including unreachable reference cycles. The generated main records the stack base via py_gc_init and registers its globals with py_gc_register_root (src/codegen.rs).
  • Classes: class definitions with methods, __init__, class attributes and instance attributes, attribute access and assignment, single inheritance with method lookup along the base chain, class instantiation, isinstance, and the __str__, __repr__, __eq__, __len__, __getitem__, __setitem__ and __contains__ protocols (src/ast.rs, src/parser.rs, src/codegen.rs, runtime/pyrt.c).

Changed

  • Removed the deprecated python_compiler alias. pycompile is now the only command-line entry point; packaging, workflows and documentation were updated accordingly.

Fixed

  • sort() and sorted() are now stable when reverse=True.

Notes and limitations

  • The garbage collector is conservative: it scans the whole C stack on each collection and may keep an unreachable object alive a little longer than strictly necessary.
  • super(), multiple inheritance, decorators, with, generators, async/await, and modules other than math/sys are not supported and produce a clear compile-time error.
  • A return, break or continue inside a try that has a finally clause is rejected at compile time.
  • An uncaught exception prints a single-line traceback (no file/line frames).

Change log

Added

  • Initial pycompile compiler: Python source is translated to C and compiled to a standalone native binary by the system C compiler (src/lexer.rs, src/parser.rs, src/codegen.rs, src/driver.rs).
  • Embedded C runtime runtime/pyrt.c / runtime/pyrt.h with tagged-union values, operators, comparisons, lists, tuples, dicts, sets, iterators, f-string formatting, and a set of builtins.
  • Supported syntax: literals and None, f-strings (format specs and !r), lists/tuples/sets/dicts and comprehensions (list, set, dict), if/elif/else, while, for-else, break, continue, pass, def with defaults, recursion, *args / **kwargs parameters, calls with positional/keyword/*/** arguments, chained comparisons, in/not in, is/is not, slicing, item and augmented assignment, the math and sys modules.
  • Two equivalent command-line entry points: pycompile and python_compiler (src/lib.rs, src/main.rs, src/bin/python_compiler.rs).
  • CLI options: -o/--output, --emit-c, --keep-temps, -r/--run, --man, -h/--help, -V/--version.
  • Terminal manual and man-page installation: pycompile man, pycompile man --install, pycompile man --prefix DIR (src/man.rs, docs/pycompile.1).
  • key and reverse support for sorted() and list.sort(), including first-class references to common builtins such as len, str, int and abs.
  • Static documentation site with install and download instructions (docs/), deployed to Vercel with zero configuration (vercel.json: no build step, outputDirectory set to docs).
  • Example programs with recorded expected output (examples/).
  • Integration tests that compile and run every example and compare output (tests/integration.rs).
  • CI workflows: validate (format/lint/build/test/examples/man page/site) and release binary builds (.github/workflows/).
  • Dependabot configuration for Cargo and GitHub Actions dependencies.
  • OS packaging: .deb and .rpm packages are built and attached to each release (Cargo.toml metadata, .github/workflows/release.yml).
  • Install channels documented in the README and install page: .deb, .rpm, Homebrew, Scoop, Cargo and prebuilt archives (AUR, Snap and winget are prepared and listed as pending first publication).
  • Packaging manifests under packaging/ and snap/ for AUR, Flatpak, Homebrew, Scoop, winget and Snap. The Flatpak manifest is provided for self-build only: Flathub is not used because the sandbox has no C compiler for pycompile to invoke.

Fixed

  • Relative output paths (for example pycompile prog.py -o prog) now write the binary into the caller's working directory instead of the temporary build directory, which was deleted afterwards. Output paths are resolved to absolute before invoking the C compiler (src/driver.rs).

Notes and limitations

  • No garbage collection: allocations are not reclaimed until process exit.
  • class, closures, nested scopes, exceptions (try/except), with, decorators, lambda, async/await, and modules other than math/sys are not supported and produce a clear compile-time error.
  • % string formatting is not supported; use f-strings.
  • sort/sorted are not fully stable when reverse=True.

After downloading

Extract the archive, then put the binary on your PATH and make it executable on Unix-like systems:

# Linux / macOS
tar -xzf pycompile-x86_64-unknown-linux-gnu.tar.gz
chmod +x pycompile
sudo mv pycompile /usr/local/bin/

# Windows (PowerShell)
Expand-Archive pycompile-x86_64-pc-windows-msvc.zip -DestinationPath C:\tools\pycompile

Verify a checksum

Download SHA256SUMS alongside your archive and check it:

sha256sum -c SHA256SUMS --ignore-missing

Install the man page

Once the binary is on your PATH, install the manual page:

sudo pycompile man --install
man pycompile

Build from source instead

No suitable binary? Build a native one for your machine:

git clone https://github.com/ramackersjp/pycompile
cd pycompile
cargo build --release
cargo install --path .

See the full install guide for details and platform notes.
