After downloading

Extract the archive, then put the binaries on your PATH and make them executable on Unix-like systems:

# Linux / macOS
tar -xzf pycompile-x86_64-unknown-linux-gnu.tar.gz
chmod +x pycompile
sudo mv pycompile /usr/local/bin/

# Windows (PowerShell)
Expand-Archive pycompile-x86_64-pc-windows-msvc.zip -DestinationPath C:\tools\pycompile

Verify a checksum

sha256sum -c SHA256SUMS --ignore-missing

Install the man page

Once the binary is on your PATH, install the manual page:

sudo pycompile man --install
man pycompile

Build from source instead

No suitable binary? Build a native one for your machine:

git clone https://github.com/ramackersjp/pycompile
cd pycompile
cargo build --release
cargo install --path .

See the full install guide for details and platform notes.
