Ahead-of-time Python compiler

Write Python.
Ship a native binary.

pycompile translates a supported subset of Python straight into C, invokes your system C compiler, and emits a single standalone executable. No interpreter. No runtime to install.

Download Install from source Read the docs
bash 
# Compile a script into a native binary
pycompile hello.py -o hello

# Run it — no Python required on the target machine
./hello
Hello, World!

# Read the full manual right in your terminal
pycompile man

Why pycompile?

Python's ergonomics, a native binary's portability.

Ahead of time

Source is translated to C and compiled by cc, gcc, clang or MSVC. What you ship is a real executable.

No runtime

The generated program links a tiny embedded runtime. Targets need nothing installed — not even Python.

Small and fast

Release builds use link-time optimization and stripping. Binaries are compact and start instantly.

Familiar syntax

Functions, defaults, *args/**kwargs, f-strings, comprehensions, dictionaries, sets and more all compile.

Clear errors

Unsupported constructs fail at compile time with a file, line and column — never a surprise at runtime.

Built-in manual

Run pycompile man for a full terminal manual, or install a real man(1) page.

Install in minutes

Requires Rust and a C compiler. Pick the path that fits you.

With Cargo

cargo install python-compiler

Installs pycompile into ~/.cargo/bin.

Full install guide

From source

git clone https://github.com/ramackersjp/pycompile
cd pycompile
cargo build --release

Binaries land in target/release/. See also installing the man page.
