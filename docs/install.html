Install pycompile

pycompile is a Rust program. Installing it gives you two commands — pycompile and python_compiler — that behave identically.

Requirements

Rust toolchain

Any recent stable Rust. Install with rustup if you do not have it:

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

A C compiler

pycompile generates C and hands it to a system compiler. On Linux/macOS install build-essential or Xcode command line tools. On Windows, install MSVC Build Tools, MinGW, or LLVM/clang.

Option 1 — Install with Cargo

Install the crate

This fetches, compiles and installs the latest published version.

cargo install python-compiler

Verify the install

Both commands must print the same version.

pycompile --version
python_compiler --version

Read the manual

Print the full manual straight to your terminal.

pycompile man

Option 2 — Build from source

Clone the repository

git clone https://github.com/ramackersjp/pycompile
cd pycompile

Build in release mode

Release builds enable link-time optimization and strip symbols for small binaries.

cargo build --release

Put it on your PATH

Binaries are in target/release/. Either copy them somewhere on your PATH, or install them with Cargo:

cargo install --path . --release

Install the man page

Once installed you can drop a real man(1) page so that man pycompile and man python_compiler work:

# Install into /usr/local/share/man/man1 (may need sudo)
sudo pycompile man --install

# Or install into a custom prefix
pycompile man --install --prefix ~/.local

# Then read it
man pycompile
man python_compiler

If you installed into a custom prefix, make sure your man path includes it (for example export MANPATH=~/.local/share/man:$MANPATH).

Quick test

Compile a hello-world and run the resulting native binary:

cat > hello.py <<'EOF'
name = "World"
print(f"Hello, {name}!")
EOF

pycompile hello.py -o hello
./hello

You should see Hello, World! — produced by a native executable with no Python involved.

Tip: set CC if you want to control which C compiler is used, for example CC=clang pycompile hello.py.

Packaging and platforms

How pycompile is distributed today, and what is planned. Nothing here affects a normal Cargo or from-source install.

Linux

Distributed as .tar.gz release archives and via cargo install. OS packages (Flatpak, Snap, AUR, .deb, .rpm) are planned but not published yet.

macOS

Distributed as .tar.gz release archives for Intel and Apple Silicon. A Homebrew formula and tap are planned but not published yet.

Windows

Distributed as a .zip release. pycompile needs a C compiler to produce binaries: install MSVC Build Tools, or use MinGW-w64 / LLVM (clang). Add the extracted folder to PATH. A winget / scoop package is planned.

Note: the compiler itself is a single native binary; the C compiler requirement applies only when you invoke pycompile to build a program.
